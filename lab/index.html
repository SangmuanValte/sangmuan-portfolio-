03 · Evidence and the next gate


This is a functional browser teaching layer, not a security boundary. Synthetic fixtures test a limited authorization algorithm, but the browser operator can forge grants and rewrite state. Even a passing local replay is not independent evidence. No actual frontier model is connected.


Future integration must treat local Qwen or hosted frontier LLM output as untrusted proposals. A separately deployed service would need authenticated human approval, isolated least-privileged execution, one-time grant consumption, trusted identity and an independently protected verifier. Deployment remains blocked pending the existing Pages failure diagnosis and separately scoped authorization.
